# 🪰 FlyOthello

一只真果蝇的连接组在你的浏览器里下黑白棋。每一步落子都由 138,639 个神经元产生，
接线与真实的果蝇大脑完全一致（但我们把这些接线随机打乱，它下棋水平一样）。

[English README](README.md) · [源码](https://github.com/hulatown/flyothello) · MIT 代码 + CC-BY 数据

---

## 诚实的结论

这个项目最初是为了好玩，但随着设计和思考的深入，一个问题随之浮现：
**果蝇真实的接线到底有没有贡献，还是说它只是一个花哨的随机特征扩展器？**

我们做了对照实验。答案是：没有贡献。

| 6×6 棋盘，9,000 个局面 | 与深度 3 引擎的落子一致率 |
|---|---|
| 随机合法落子 | 0.275 |
| **真实连接组** | **0.4578** ± .0230 |
| **打乱的连接组**（度分布匹配） | **0.4472** ± .0230 |
| **完全不用果蝇**（棋盘直接线性回归） | **0.5122** ± .0231 |

- **真实 vs 打乱：+0.011，McNemar p = 0.347。不显著。**
  果蝇的拓扑结构与一个度分布相同的随机图无法区分。
- **无果蝇 vs 真实：+0.054，p < 0.00001。** 完全不用果蝇反而**更强**。

早前用 3,000 个局面跑出过 real > shuffled、p = 0.047 的结果。样本量扩大三倍后，
效应从 +0.045 缩到 +0.011，显著性消失。教科书式的假阳性。确认性检验的分析方案
是在**见到数据之前**写好并锁定的，就在仓库里：
[`tools/pipeline/confirm6.py`](tools/pipeline/confirm6.py)，假设与判据都写在它的
文档字符串里。

所以：果蝇确实会下棋，对随机落子的胜率有 65–75%。但起作用的是“中间有一个复杂的
非线性系统”这件事本身，而不是“它是一个果蝇大脑”。

我照样把它做完发布了。因为一个你能亲手玩的否定结果，比又一个跳过对照的 demo 有意思得多。

## 它到底怎么工作

```
棋盘状态
  └─ 视角归一化（当前走子方永远呈现为“黑”）
  └─ 每格 → 一个亮度 → 一个发放频率（10 / 50 / 190 Hz）
      ↓
  33,208 个视觉中继神经元（T4、T5、Tm、TmY 类型）
  按视网膜拓扑排布，每格约 261 个神经元“看见”
      ↓
  全脑漏电积分发放模型，30 毫秒生物时间
  138,639 个神经元 · 2,700,513 条突触 · 接线永不改变
      ↓
  从 1,933 个视觉投射神经元读取脉冲计数
      ↓
  一个训练过的矩阵（1,933 × 64）→ 64 个落子分数
  → 用合法性掩码过滤 → 取最高分，或按温度采样
```

**整个系统里唯一被训练过的，就是最后那个矩阵。** 连接组的 270 万条突触是固定的。
这是储备池计算，只不过储备池用的是一只真实动物的接线。

### 为什么棋盘注入在中继层，而不是眼睛（即直接让果蝇来“看”）

最诚实的设计本应是把棋盘渲染到果蝇的六边形视网膜上、驱动光感受器。**这条路走不通**：
即使把驱动强度提高 4 倍，也没有任何一个下行或运动神经元放电。原因是光感受器和
层状/髓质神经元是**分级电位神经元**，本来就不发放动作电位，而全脑 LIF 模型把所有
神经元一律当作发放型处理。信号死在髓质：

| 层 | 活跃 |
|---|---|
| R1-6 光感受器 | 7932 / 7932（被驱动） |
| L1 / L2 | 约 31% |
| L3 | 13% |
| Tm1 / Tm2 | 9–13% |
| **Tm9 / T4 / T5** | **0** |

所以棋盘改为注入到下游一级。这是一个真实的局限，也是为什么我们的说法是“棋盘被
注入到果蝇的视觉中继层”，而不是“果蝇看见了棋盘”。

### 棋盘信息在哪儿

从不同深度的神经活动中把棋盘解码回来：

| 读出位置 | R²（每格状态） |
|---|---|
| 视叶 | 0.379 |
| 视觉投射神经元 | 0.293 |
| 中央脑 | 0.044 |
| 下行神经元 | 0.030 |

随着离注入点越远而**单调衰减**。 这是有损信道的特征，不是计算的特征。读出层设在
视觉投射层，因为那是棋盘最后一个还能被还原出来的地方。

## 运行

```bash
npm install
npm run dev          # 打开终端里打印的地址
npm run build        # 静态产物在 dist/
```

全部在客户端运行，没有服务端。首次加载约 14 MB 连接组（gzip 后约 9 MB），之后
桌面端每步约 300 毫秒。

神经元活动的实时视图，投影在大脑的正面观上。你会先看到左右两个**视叶**亮起（注入点），然后信号向中间扩散。
这也就是上面那张衰减表的动画版。

## 验证

仿真实现了两遍。Python 一份用于研究流水线，TypeScript 一份用于浏览器 —— 并且
互相对照检查。

```bash
export FLYOTHELLO_DATA=/研究数据目录
python3 tools/verify_sim.py       # 产出期望脉冲数
npx tsx tools/verify_sim.mts      # 对比：0.00% 偏差，逐位一致
python3 tools/verify_policy.py    # 产出期望分数与落子
npx tsx tools/verify_policy.mts   # 对比：落子完全相同，分数偏差约 1e-9
npx tsx tools/bench.mts           # 计时
```

研究流水线以及大体积数据文件的获取方式见 [tools/README.md](tools/README.md)
（这些文件不在本仓库中）。


## 这不是什么

它不是意识的证据，不是果蝇的完整复刻，也不是一只理解黑白棋的果蝇。它是一张接线图
加一个七参数的点神经元模型，外面套了一个学会读它的线性层。这个模型没有可塑性、
没有神经调质、没有内部状态。它学不会任何东西，也不记得上一步下在哪。
